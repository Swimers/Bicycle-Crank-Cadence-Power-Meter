# CadenceSensor 后续电路与功能改进清单

## 1. 结论与适用范围

建议先做**电桥节电、比例测量、标定与温漂处理、诊断与测试接口**，再考虑换封装、减少接口和进一步缩板。它们对续航、测量可重复性和后续调试的收益，比单纯增加 ADC 位数更直接。

本文以用户已修正此前问题、当前电路具备既定基本功能为前提，不重复把历史问题列为待修复项，也不代表对未重新提供的最终工程做了验收。现有架构为 nRF52832、SC7A20H、ADS1220、350Ω双应变片半桥、nPM1100及板载BLE天线。

电池温度输入继续采用已确认的固定10kΩ方案；本次不建议将其改回NTC。板外电池包的规格与保护条件按既定方案落实。

优先级：**P1＝优先实现；P2＝下一版按验证结果选择；P3＝长期演进。**“软件先做”不表示零成本，仍需测量和验证。

## 2. 改进列表与简单实现思路

| 优先级 | 改进项目 | 收益 | 简单实现思路 | 主要代价／验证点 |
|---|---|---|---|---|
| P1 | 可控电桥激励 | 降低静止和休眠电流 | 增加低漏电高边负载开关或受控P沟道MOSFET，默认关闭；采样前开启，等待稳定后启动ADC | 检查开关压降、漏电、初始热漂移和参考连接；不能只让ADC休眠 |
| P1 | 比例式测量 | 降低激励电压变化引起的比例误差 | 电桥与ADC使用同一激励基准；简单版本选择AVDD−AVSS为参考；增加激励开关后，再决定是否用REFP0/REFN0直接感测桥端电压 | 必须覆盖开关、线缆与地回路的压降；桥端参考电压和ADC供电需始终满足手册要求 |
| P1 | 固定桥臂精度与温漂 | 减少零点占用与温度漂移 | R4/R16采用低温漂、良好比值跟踪的精密电阻；同型号、同封装、同朝向靠近放置，远离热源 | 单纯提高绝对精度不能代替电阻比值跟踪和整机标定 |
| P1 | 完整功耗状态机 | 将节电措施变成稳定行为 | 运动测量、静止监听、低电量、运输关机分级；SC7A20H中断唤醒，按需采样/广播；退出前逐项恢复外设 | 分别测状态电流和切换失败条件；Ship与MCU System OFF的硬件供电行为不同 |
| P1 | 标定参数与质量信息 | 让功率数据可追溯 | 保存零点、扭矩斜率、方向、温度系数、硬件版本和CRC；BLE提供标定入口与结果状态 | 参数原子更新、恢复默认、掉电中断写入；减少Flash写入频率 |
| P1 | 扭矩与角速度同步 | 改善变速、非均匀踩踏时的功率估计 | 给ADC、加速度数据加时间戳；使用同一时间基准；比较逐点平均的T×ω与简单均值法 | 采样带宽、相位延迟、滤波延迟均要标定；不能仅靠增加采样率解决 |
| P1 | 应变温度补偿 | 改善户外温变下零点稳定性 | 先采集无载零点随温度的变化；需要时在靠近应变片/曲柄位置增加温度测量，拟合零点与比例系数 | MCU/ADC内部温度主要反映芯片温度，不能直接视为曲柄温度；此项不涉及电池NTC |
| P1 | 自动零点与异常零点保护 | 降低用户重复归零负担 | 仅在已确认无载的状态下更新零点，并保留手动归零；限制更新幅度、速率和温度范围 | “无运动”不等于“无载”，人踩住静止曲柄时不应自动归零 |
| P1 | 硬件自检与故障码 | 区分掉线、饱和与传感器故障 | 检查传感器身份、ADC寄存器回读、DRDY超时、输入共模/差分越界、电池采样合理性；向BLE报告状态 | 电桥断线、脱胶不能仅靠单一ADC阈值判断；先做可验证的故障分类 |
| P1 | 小型化SWD与测试点 | 降面积并保留可调试性 | 2.54mm排针改为背面弹簧针焊盘；保留VTref/GND/SWDIO/SWDCLK/RESET，以及电源和模拟节点测试点 | 先确认探针直径、定位孔、治具压合与焊接面，不能只画最小焊盘 |
| P1 | 压低常驻指示功耗 | 降低无功能收益的持续耗电 | 电源常亮灯设DNP或改短时指示；受控灯与蜂鸣器按事件输出 | 实测关断漏电；保留生产测试可见性，不要求增加更多LED |
| P1 | USB与外接引线防护 | 提高反复插拔与现场稳定性 | 按接口位置配置合适的VBUS/信号ESD防护；应变引线入口增加受控泄放/保护预留 | 模拟保护器件漏电、失配和寄生可能影响微弱信号，须测零点与温漂 |
| P2 | 低噪声采样窗口 | 抑制蜂鸣器和负载扰动 | 发声、指示灯PWM、充电模式变化时暂停有效采样或标记无效；实测后选择PMIC的MODE策略 | 不能随意停掉协议栈时序；模拟RC、电桥热稳定和ADC数字滤波都影响恢复时间 |
| P2 | 模拟电源分支优化 | 减少电源串扰 | 先为模拟支路预留0Ω位置；有噪声证据后再尝试阻尼RC、磁珠或独立低噪声稳压 | 避免未经计算叠加LDO/磁珠；考虑共振、压降、有效电容、激励参考一致性 |
| P2 | 电池估算与充电状态 | 改善低电量体验 | 用受控采样与标定估算电压；静置或轻载时评估SOC，加入迟滞；有需求时读取CHG/ERR状态 | 充电中电压不能直接当作真实SOC；CHG/ERR若连VSYS供电LED，不能直接并到MCU GPIO |
| P2 | 独立蜂鸣器/LED控制 | 提高提示灵活性 | 若当前联动不满足需求，分配独立GPIO；蜂鸣器按实际器件用合适PWM、钳位和低栅压MOSFET驱动 | 注意声学开孔、防水、瞬态电流；蜂鸣器是可选空间/功耗项 |
| P2 | 标准骑行功率服务与升级 | 改善码表兼容性与维护 | 在现有BLE数据基础上评估[Cycling Power Service](https://www.bluetooth.com/specifications/specs/cycling-power-service/)、标准控制流程与固件升级；预留版本与升级结果查询 | 需要真实码表互通测试；先核算Flash、RAM、Bootloader与升级分区 |
| P2 | 更紧凑ADC封装 | 缩小模拟区 | 在下一版评估ADS1220 VQFN替代TSSOP；重新建符号、焊盘与引脚映射，按装配能力处理裸露焊盘 | 不可直接替换封装；先看连接器和天线是否才是真正面积瓶颈 |
| P2 | 充电/电池/应变接口缩小 | 减少大接口占用 | 在可维护性允许时，电池和应变接口改焊盘/小连接器；评估密封充电触点替代USB-C | 这是产品结构选择，不能只为缩板牺牲防反接、线缆固定和售后更换 |
| P3 | 四有源应变片或机械测量结构升级 | 改善灵敏度与温度抵消能力 | 结合曲柄受力分析确定四片位置和桥臂极性，再做静态与动态标定 | 不保证仅换全桥就提高精度；四个350Ω桥臂仍是约8.57mA激励，不会自动省电 |
| P3 | 主控/PMIC体系进一步集成 | 进一步缩板或扩展能力 | 有体积、功耗或资源测量证据后，再评估其他封装或更集成器件 | 软件迁移、RF匹配、认证和采购风险显著，首版不建议同时重构 |

## 3. 建议先做的四个小改造

### 3.1 电桥高边开关及参考策略

当前四个350Ω桥臂在3V下连续消耗：

```text
I_bridge = 2 × 3V / (350Ω + 350Ω) ≈ 8.57mA
P_bridge ≈ 25.7mW
```

建议结构：

```text
VOUT → 高边开关 → BRIDGE_EXC → 半桥 → BRIDGE_RETURN → GND
                     │                    │
                 可选桥端参考正       可选桥端参考负
```

1. 开关应有确定的上电默认关闭状态，检查掉电反灌、关断漏电与GPIO驱动范围。
2. 休眠时关闭激励；正常踩踏期间先保持连续激励以获得稳定数据，再评估间歇激励。
3. 不把占空比与总功耗简单画等号：频繁启停可能产生热漂移，稳定时间也会吃掉节电收益。
4. 桥端参考使用专用REFP0/REFN0时，激励开启并稳定后才能转换；关闭时进入安全状态。若继续用AVDD−AVSS参考，须把开关及回流压降误差计入预算。
5. 先实测唤醒到稳定的时间，再确定固件等待时间，不能只使用1kΩ/100nF的RC常数估计全部建立过程。

比例测量及外部参考输入的电压、共模和配置条件以[ADS1220手册](https://www.ti.com/lit/ds/symlink/ads1220.pdf)为准。

### 3.2 零点、扭矩和功率的验证顺序

| 阶段 | 方法 | 应留下的记录 |
|---|---|---|
| 零点 | 无载、不同温度与电池电压下记录ADC原码 | 均值、峰峰值、时间漂移、恢复时间 |
| 斜率 | 已知力与力臂、多点加载与卸载 | 线性、迟滞、重复性、过载后的零点变化 |
| 踏频 | 与已知转速或外部参考比较 | 稳态误差、启停延迟、不同安装半径影响 |
| 功率 | 让扭矩与角速度对齐，动态对比参考 | 延迟、平均窗口与数据丢失处理 |

如果只测单侧曲柄，须明确输出是单侧功率，还是基于左右对称假设估计的总功率；不能把后者当作直接测得的双侧功率。

### 3.3 先建立功耗账本，再增减器件

记录“静止监听、正常骑行、发声、充电、MCU休眠、Ship”各状态电流。对于稳压输出侧负载：

```text
平均输出功率 ≈ 各状态的（输出电压 × 状态电流 × 时间占比）之和
平均电池电流 ≈ 平均输出功率 /（平均电池电压 × 实测等效效率）+ 其他电池侧电流
续航时间 ≈ 可用电池容量 / 平均电池电流
```

电池容量、温度、截止电压与效率未知时，不给出精确续航承诺。nPM1100的Ship是断开电池供电路径；USB接入及SHPHLD动作条件以[官方说明](https://docs.nordicsemi.com/r/bundle/ps_npm1100/page/product_overview.html)为准。

### 3.4 给测量性能建立可比较的基准

每次改布局、滤波、供电或器件，只比较同一机械安装、同一量程和同一采样设置下的数据。至少保留：零点噪声、温漂、发声干扰、BLE发射干扰、充电干扰与功耗。先找限制因素，再换器件。

## 4. 实施顺序

| 阶段 | 建议范围 | 完成标志 |
|---|---|---|
| 当前PCB前 | 电桥开关预留、模拟支路0Ω、测试焊盘、天线匹配预留、完整BOM | 能布局、能测量、能修改，不扩大第一版架构 |
| 第一轮样机 | 状态电流、静态标定、同步采样、基础诊断 | 核心误差和功耗来源有数据 |
| 第二轮优化 | 依据测量选择温度传感器、供电过滤、封装与接口缩小 | 带来可测收益，未引入明显新问题 |
| 后续产品化 | 标准BLE服务、升级、生产校准、密封与安装可靠性 | 可重复生产并在实车环境中稳定运行 |

## 5. 与布局方案配套使用

面积优化、层叠、天线与模拟回流规划见[四层PCB紧凑布局与布线方案](CadenceSensor_4Layer_PCB_Layout_Plan.md)。优先把改进中的“预留位”画入原理图与BOM，并明确默认焊接/DNP状态，避免后续PCB只有空位却没有明确网络。
