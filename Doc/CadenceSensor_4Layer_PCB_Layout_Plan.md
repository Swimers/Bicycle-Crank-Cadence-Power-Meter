# CadenceSensor 四层PCB紧凑布局、布线与检查方案

## 1. 推荐方案与边界

采用**四层板、关键器件顶层放置、背面承担测试焊盘和少量非关键器件、板端布置BLE天线**。先固定位于外壳边缘的天线与接口，再布置MCU/RF、模拟采样和电源回路；缩板主要靠减小接口、合理封装与功能簇紧凑排布。

本方案以用户确认原理图已修正、基本功能成立为前提，是布局执行方案，不是对最终原理图、PCB或RF性能的验收。

当前没有外壳内尺寸、PCB外形、电池相对位置、曲柄与天线间距、板厂层叠及完整天线参考布局，因此不承诺具体最小长宽或固定RF线宽。初次EDA摆放后，用完整封装、装配间距、天线净空和走线通道反推板框。

**板载BLE天线按现有贴片陶瓷天线方向规划。**如果后续改成PCB印制天线，需要重新分配板端长度、地平面和匹配，不能直接把本方案的陶瓷天线焊盘换成一段铜线。

建议同时比较：保留USB-C的可维护版本，以及接口缩小但功能不变的版本。是否取消USB-C、蜂鸣器或独立按键由产品需求决定，不在本方案中默认删除。

## 2. 面积优化的优先顺序

| 顺序 | 措施 | 具体执行 | 不应牺牲的条件 |
|---|---|---|---|
| 1 | 缩小大间距接口 | SWD改弹簧针焊盘；评估电池/应变片2.54mm连接器改焊盘或小型连接器 | 调试治具可达、线缆应力释放和返修 |
| 2 | 按功能簇摆放 | 每个IC与去耦、晶振、滤波、电感形成小组，再拼接各组 | 回流路径、RF参考几何和局部散热 |
| 3 | 合理用背面 | 测试点、小电阻、非关键控制网络可放背面 | 不占天线净空，不堵电池/结构空间，不在敏感区正下方放噪声源 |
| 4 | 常规阻容0402 | 数字上拉、串阻、小去耦优先0402；其他按实物能力选择 | 电容有效容量、耐压，电阻功率与精度 |
| 5 | 精简可选器件 | 无需常亮的LED设DNP；把扩展接口改测试点 | 第一版仍保留必要测量入口 |
| 6 | 改主IC封装 | 如模拟区确为瓶颈，再评估ADS1220 TSSOP改VQFN | 新引脚映射、钢网、裸露焊盘及装配良率 |
| 7 | 再收缩板框 | 用已完成关键布线的布局迭代外形 | 不压天线窗口，不把USB、蜂鸣器或电源挤到ADC旁边 |

不优先使用0201、盲埋孔或任意缩小焊盘；先用普通四层通孔工艺验证功能与可制造性。板面积小不等于整机体积小，还应比较电池、连接器、蜂鸣器和外壳厚度。

## 3. 四层叠层与参考地

### 3.1 首选分配

| 层 | 主要用途 | 执行要求 |
|---|---|---|
| L1 顶层 | 主器件、RF、晶振、ADC模拟输入、关键短线及局部地 | 射频和敏感模拟尽量不换层 |
| L2 内层1 | 主要连续GND参考面 | 普通信号下方不切地、不布电源；天线与芯片RF局部按验证过的参考图例外处理 |
| L3 内层2 | GND为主，必要的电源通道/小区域 | 为L4走线保留连续参考；禁止把整个L3切碎后又把L4当作有完整参考面的高速层 |
| L4 底层 | 辅助信号、电源分配、测试点、少量器件及地 | SPI等有较快边沿的信号只在L3有连续参考时使用此层；其他情况尽量留L1 |

这是偏向小型混合信号板的分配选择，不要求独占一整层电源平面。若最终改用L3大面积电源区，必须逐条复核L4信号的实际回流路径，不能只依据信号频率低就忽略数字边沿。

### 3.2 地与回流的处理

- 默认使用统一GND，通过摆放与走线路径隔开模拟、开关、电磁负载和RF回流，不额外切出一块浮动AGND。
- ADS1220的AVSS、DGND短接到就近同一低阻地参考，不用细长线串联后再回电源。
- L1与L4信号换层时，在附近安排接地过孔，使相邻地参考之间有短回流路径。
- 大电流支路直接回其电源/去耦区域，不经桥路低端、ADC输入区或晶振区域绕行。
- 地过孔不能替代连续平面；检查过孔反焊盘是否在密集区域割裂地层。

ADC模拟/数字区域的物理分区与去耦依据[ADS1220布局章节](https://www.ti.com/lit/ds/symlink/ads1220.pdf)，本项目选择统一地平面以降低误切回流的风险。

### 3.3 先与板厂确认的参数

确认总板厚、各层铜厚、介质厚度/Dk、阻焊、最小线宽间距、孔径与阻抗控制能力。0.8mm或1.0mm可作为紧凑板的结构候选，需同时评估连接器匹配和板弯；不直接指定未经板厂确认的RF线宽。

RF线宽和侧边地间距由实际层叠计算，并与板厂复核。板厚、参考层或局部铜结构改变后，需要重新计算。

## 4. 功能分区与摆放规划

以下仅为相对分区，不按比例、不代表具体天线净空尺寸；左右可镜像，原则保持不变。

```text
                   朝远离金属曲柄的板端／塑料窗口
  ┌────────────┬──────────────────┬──────────────────┐
  │ A 天线区域 │ B nRF52832       │ D USB-C、nPM1100 │
  │ 及专属净空 │ RF匹配、晶振     │ 电感、充电电容   │
  │ 不安排背面 │ 去耦、DC/DC      │ 电源与充电热区   │
  │ 电池或器件 ├──────────────────┼──────────────────┤
  │            │ C ADS1220        │ E 蜂鸣器驱动     │
  │            │ 精密桥臂、输入RC │ 电池/电源接口    │
  └────────────┴─────────┬────────┴──────────────────┘
                        SG引线入口（靠近C区）
```

这里的相邻块不等于允许紧贴：D/E的SW节点和蜂鸣器回路必须朝远离C区的一侧收拢。若实际板宽不足，先移动电源/声学区或调整板框，不能让它们从C区背面穿过去。

### 4.1 A区：天线先于其他器件确定

1. 天线放在满足厂商参考位置的板端/角部，并尽量朝向外壳的非金属区域；具体位置服从实际天线资料。
2. 在EDA中同时建立器件禁布、各铜层禁布及结构禁入区域，标明哪些区域必须留地、哪些区域必须清空。
3. 不把“天线封装尺寸”当作“天线占用面积”；其地平面尺寸、净空和外部空间常比器件本身更关键。
4. 电池铝塑膜、金属曲柄、螺丝、USB壳体、蜂鸣器金属部分和线束均不进入天线要求的空间。
5. 不能依赖PCB局部挖空解决外部曲柄紧贴天线的问题；结构上需提供足够非金属窗口与离金属距离，并在实物上验证。
6. 不任意给AN2051-245指定通用的5mm或10mm净空。当前未获得可核实的完整厂商参考铜图，应先取得与采购版本一致的资料再锁定该区域。

若预留空间与天线参考尺寸冲突，优先扩大天线端、调整外壳或换适合该地平面尺寸的天线，而不是强行压缩净空。

### 4.2 B区：nRF52832及周围关键小组

| 小组 | 摆放方法 | 禁止的做法 |
|---|---|---|
| MCU方向 | ANT引脚朝向天线；SPI方向尽量朝ADC | 为缩短普通GPIO而拉长RF匹配路径 |
| VDD/DEC去耦 | 先放各脚对应电容，再安排逃线；目标是引脚到电容路径约1–2mm或更短 | 把不同DEC节点合并，或集中放一排远离芯片的电容 |
| MCU DC/DC | DCC、电感和DEC4电容组成短回路，按QFAA参考相对位置布置 | 将10µH与15nH当作任意可远置的电感 |
| 32MHz晶振 | 靠近XC1/XC2，同面，短而紧凑，两负载电容贴近对应端 | SPI、SW、蜂鸣器信号穿越晶振及其正下方 |
| 32.768kHz晶振 | 靠近XL1/XL2，远离开关节点和外部高阻污染路径 | 用长线绕开其他器件后才接晶振 |
| 裸露焊盘 | 按参考设计安排接地过孔、钢网与焊盘 | 不确认填孔/塞孔工艺就让大量开放过孔吸走焊锡 |

上述距离是摆放目标，不是替代参考布局的厂家硬限制。实际RF和去耦图形优先遵循[QFAA参考设计](https://docs.nordicsemi.com/r/bundle/ps_nrf52832/page/ref_circuitry.html)。

### 4.3 C区：桥路与ADC作为一个模拟小岛摆放，地保持相连

推荐信号顺序：**SG引线入口 → 桥臂中点 → 两颗输入串阻 → 跨输入差分电容 → ADC AIN脚**。ADC旋转方向应让模拟脚朝桥路、数字接口朝MCU。

- C7及R22/R23集中在ADC输入一侧，C7靠近AIN脚；输入滤波到引脚路径以约1–2mm为目标。
- R4/R16相邻、同方向、同热环境；不要让其中一颗靠充电IC、另一颗靠板边冷区。
- AVDD与DVDD各自去耦就近落地，别用一颗远置电容代替两脚去耦。
- AIN差分两线短、并行、环境对称，尽量同层、少过孔；无需为低频信号刻意蛇形等长。
- 桥路激励与返回单独布线回供电参考，避免共享蜂鸣器/USB的大电流窄线。
- 应变片接口不放在天线端；引线尽快离开数字和开关回路，并留固定、点胶和应力释放空间。
- 不让蜂鸣器、电感或充电热区与桥路固定电阻上下叠放。

### 4.4 D区：USB与nPM1100形成紧凑电源簇

- USB-C先按外壳开口、插头进入路径、壳脚焊接和装配距离固定，确认插拔载荷不会传给模拟区。
- ESD器件靠连接器入口；VBUS去耦、PMIC及地回路靠近，避免受保护线段先绕进板内再回TVS。
- PMIC、L2、C8按参考布局组成小回路；SW铜面积只满足连接和载流，不铺成长条测试线或大铜面。
- C6/DEC、C11/VSYS、C2/VBAT分别靠各自引脚，不因为名字都叫电源电容就随意合并。
- 输出分支从输出电容附近展开，分别到MCU、模拟/桥路和蜂鸣器，避免串联供电经过多个模块。
- 充电IC的热量通过其规定的接地/散热结构散出，并远离R4/R16与应变片入口。
- SW下方是否局部禁铜按PMIC参考布局处理，不使用“所有电感下方全部挖地”的通用规则。

可以直接参考仓库中的[nPM1100开发板电路和PCB](../NPM1100/Schematic_Layout%20pdf%20files/PCA20057_Schematic_And_PCB.pdf)进行相对摆放核对，具体芯片封装须匹配。

### 4.5 E区及SC7A20H

- 蜂鸣器靠外壳声学开口；Q2、钳位器件和电源回路靠近蜂鸣器，不围住ADC。背面放蜂鸣器只有在结构高度、回流和噪声都允许时才有面积收益。
- 蜂鸣器支路回流直接回电源区，PWM线不沿ADC输入、晶振或天线走。
- SC7A20H放在机械固定较稳定、安装方向明确的位置，避开连接器、板边受力区、螺丝应力和蜂鸣器振动；不要仅因空位而放在易弯的狭长舌片上。
- 记录加速度计相对曲柄轴的方向和安装半径，供固件标定使用。
- Battery和控制网络可向背面转移，但不占天线空间，不使电池更贴近天线或压在器件上。

## 5. RF布线必须区分三部分

```text
nRF ANT引脚 → 芯片匹配/谐波网络 → 50Ω参考点 → 50Ω馈线 → 天线调谐网络 → 天线
```

1. **芯片匹配段不等于通用50Ω线。**优先复制QFAA匹配器件的相对位置、焊盘、局部地、VSS回流与参考几何，不自行套固定线宽。
2. **50Ω馈线**选定明确的参考地层，按层叠计算微带或接地共面波导；RF线尽量同面、无支路、无过孔，侧边地连续并合理布地过孔。
3. **天线调谐及辐射段**按天线厂商参考处理，包含天线匹配预留、地边界和各层净空；不能把馈线下方参考地也一起挖掉。

预留紧凑π型调谐位时，要区分它与芯片原有匹配网络。默认焊接/DNP状态、量测参考点和网络编号应清楚；不要在未测量时随意加一组匹配值。

Nordic较早的[通用布局指导](https://devzone.nordicsemi.com/guides/hardware-design-test-and-measuring/b/nrf5x/posts/general-pcb-design-guidelines-for-nrf52)讨论了多层板RF附近的局部铜结构。执行时以当前QFAA参考Gerber与实际叠层为准：如果局部挖掉L2，就不能继续按L1−L2结构计算该段50Ω。明确保留哪一层地，并重新核算；不要把文字建议变成整个RF路径或天线区域的盲目整层挖空。

RF测试接口不宜形成未终端的T形长支路。优先用可切换串联位、调试专用连接方式或合适的RF测试连接器；空间不够时至少保留可拆分的馈线量测方案。

最终在**装好电池、外壳、线缆并固定到真实金属曲柄**的状态下检查天线匹配及BLE表现。S11良好不等于辐射效率或骑行姿态下链路一定良好，还需实际通信与方向性验证。

## 6. 非RF布线规则与紧凑工艺起点

下表是初始工程建议，不是已经批准的板厂规则；按实际铜厚、压降、装配能力和信号条件调整。

| 对象 | 起点／布线方法 | 检查重点 |
|---|---|---|
| 普通数字线 | 0.15mm左右，QFN局部逃线视工艺收窄 | 不穿模拟输入/晶振区，不跨参考地缝 |
| 低频差分模拟线 | 约0.15–0.25mm，两路同环境 | 输入电阻与保护漏电对称，避免长距离靠近PWM/SW |
| 主供电与蜂鸣器支路 | 约0.3–0.5mm或短铜面起步，再按峰值电流/压降核算 | 焊盘收颈、过孔瓶颈及回流路径，而非只看主干线宽 |
| SPI串阻 | 优先靠实际驱动源：SCK/MOSI/CS靠MCU，MISO/DRDY靠ADC | 走线很短时不为形式上的源端摆放破坏分区；最终用波形确认 |
| I²C | SDA/SCL短而相邻，上拉放在方便供电与布线处 | 电容、上升沿和上拉电流，不为I²C做无意义蛇形等长 |
| BAT_MON高阻节点 | 短线、远离污染与开关节点 | 清洗残留和涂覆工艺对漏电的影响；测试点不过度加长引线 |
| 通孔过孔 | 成品孔0.2–0.3mm、焊盘约0.45–0.6mm可作为询厂起点 | 厂商能力、纵横比、焊环、孔到铜与层间参考连续性 |
| RF地围栏 | 馈线附近可从约1–2mm间距评估 | 以参考结构为准；不延伸进天线禁铜区形成额外屏蔽 |
| 去耦接地 | 地焊盘旁就近落地过孔，电源与地回路短 | 不让电容地先串经过其他器件再到地面 |
| 安装孔/板边 | 按外壳、公差、板厂及爬电要求设禁布 | 铜离切边、螺丝金属范围、连接器机械支撑 |

四层铜图应逐层检查，不只看顶层“走通”。避免为过孔阵列留出长而窄的地桥，也不要把电源走线从天线净空底层偷过。

## 7. 建议的实际布局流程

1. **锁定输入资料**：完整BOM、器件封装、结构窗口、电池外形、线缆方向、按键与USB位置、可接受高度。
2. **先锁天线和机械**：取得天线参考图，建立各层净空与3D禁入区；画板框、安装点、USB壳体和插头包络。
3. **放关键簇**：MCU/RF/晶振与去耦、PMIC/电感/电容、ADC/桥臂/RC分别完成局部摆放。
4. **拼接并缩面积**：保持RF与模拟路径，转移测试点和低敏感器件到背面，缩小连接器与冗余空白。
5. **先布关键线**：RF、晶振、模拟输入、开关电源、去耦与大电流回路；再布SPI、I²C、控制和测试线。
6. **复查参考平面**：看每段关键线下面是什么，修复地缝、窄桥和换层回流；再完成覆铜与地过孔。
7. **3D/DFM检查**：核对电池、壳体、螺丝、线束、探针、焊接工艺和装配顺序，再定最终板框。
8. **投板前评审**：导出四层铜图、顶底丝印、尺寸图、BOM、阻抗要求及可达测试点；逐项签出检查表。

面积迭代以“关键簇能布通并满足机械/RF条件”为停止条件，不以视觉上无空白为目标。

## 8. 主要检查清单

### 8.1 结构与小型化

- [ ] 板框、板厚、固定点、最高器件、电池和壳体有完整3D包络。
- [ ] USB插头、按键行程和探针压合可达，调试不需破坏产品。
- [ ] 应变引线有应力释放；PCB固定/插拔力不直接改变桥路机械应力。
- [ ] 背面器件和测试点不与电池、胶层、曲柄或天线净空冲突。
- [ ] 采用较小封装后，有效容量、功率、精度及装配良率仍满足要求。

### 8.2 射频

- [ ] 天线厂商、型号和版本已锁定，净空、地平面边界与安装方向来自对应参考资料。
- [ ] 天线空间包含所有铜层、器件、电池、线缆、螺丝和外部金属约束。
- [ ] 芯片匹配段、50Ω馈线、天线调谐段在图纸中明确区分。
- [ ] 50Ω馈线使用实际层叠与实际参考地计算，不套通用线宽。
- [ ] RF匹配回流、VSS邻接与局部铜结构按QFAA参考核对；无长支路和跨缝。
- [ ] 保留可量测/调谐方式，并计划装到曲柄后的匹配及BLE方向性测试。

### 8.3 电源与模拟

- [ ] PMIC SW回路、输入/输出电容和MCU DC/DC回路紧凑，焊盘及接地过孔无瓶颈。
- [ ] VOUT总有效电容及新增滤波支路纳入同一预算，满足PMIC规定。
- [ ] 蜂鸣器与无线峰值同时出现时，稳压、电池和连接路径仍有电流/压降裕量。
- [ ] ADC模拟输入、桥臂及参考线远离SW、PWM、充电热区和RF路径。
- [ ] R4/R16热环境对称；AVSS/DGND短接到同一就近参考。
- [ ] 信号换层、跨分区时回流连续，模拟区背面没有噪声源。

### 8.4 工程与制造

- [ ] 使用已修正原理图导出的网络表，ERC/DRC无未解释问题。
- [ ] 所有IC、MOSFET、二极管、按键、晶振和连接器逐脚核对实际封装。
- [ ] 裸露焊盘、过孔、钢网开口和孔中吸锡风险已与装配工艺匹配。
- [ ] 天线及RF器件DNP/焊接状态明确；BOM无NC容量或含糊的替代型号。
- [ ] Gerber各层禁铜、地平面、钻孔、阻抗说明与EDA工程一致。
- [ ] 裸板可测GND/电源短路，装板后可接SWD并测VBAT/VSYS/VOUT/桥路/ADC。

### 8.5 首板实测

- [ ] 限流上电、充电、插拔USB及低电量时没有异常掉电/复位。
- [ ] ADC零点在BLE发射、蜂鸣器和充电动作下的变化有记录。
- [ ] 状态电流、自动关机、按键关机、按键/USB唤醒均已验证。
- [ ] 装壳、安装电池与金属曲柄后，BLE与测量重复性仍满足目标。
