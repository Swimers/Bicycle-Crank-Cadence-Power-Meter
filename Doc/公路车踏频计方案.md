## 三、曲柄应变片布局与机械设计

这一部分比选哪颗 ADC 更重要。

### 3.1 首先明确测量目标

我们要测量的不是普通弯曲应变，而是能够反映曲柄绕中轴旋转的有效驱动扭矩。

设曲柄长度为 $L$，踏板切向力为 $F_t$：

$$
\tau_{\text{crank}}=F_tL
$$

而应变片测量的是曲柄表面某个方向的局部应变：

$$
\varepsilon=\frac{\Delta L}{L_{\text{gauge}}}
$$

两者之间需要通过机械结构建立映射：

$$
\tau_{\text{crank}}=K_{\tau}(\varepsilon-\varepsilon_0)
$$

这里的 $K_\tau$ 必须通过已知力矩加载标定，而不能仅凭曲柄长度和材料弹性模量确定。

### 3.2 两片应变片的位置建议

对常见扁平铝合金左曲柄，建议先实验验证一对对驱动方向弯曲响应相反的表面。

> [Diagram]

理想情况下，SG1 在目标载荷下受拉，SG2 受压，两片都沿测得的主应变方向布置。

需要纠正一个很容易犯的错误： 不能默认曲柄的内外宽面一定形成目标驱动扭矩下的一拉一压。对于扁平曲柄，目标弯曲的拉压表面可能是上下窄边，也可能因实际截面、安装方向而改变。

因此实际贴装建议是：

| 项目 | 建议 |
| --- | --- |
| 曲柄 | 第一版优先选择实心或结构简单的铝合金左曲柄 |
| 候选位置 | 距中轴约 40–70mm 的平直区域，需实测 |
| SG1 | 目标载荷下产生正应变的表面 |
| SG2 | 目标载荷下产生负应变的对应表面 |
| 栅丝方向 | 优先沿曲柄长度方向 |
| 阻值 | 1000Ω 优先，350Ω 作为备选 |
| 灵敏系数 | 常见金属箔式 GF≈2 |
| 粘合剂 | 专用应变片胶 |
| 保护 | 绝缘、防潮、机械缓冲涂层 |

仅靠两片应变片一般无法完全分辨驱动弯矩、侧向弯曲和轴向载荷。应把多方向加载串扰测试列为必须完成的验证项目。

### 3.3 双应变片半桥连接

采用两片有源应变片，加上两颗精密补桥电阻，构成完整惠斯通电桥。

> [半桥原理示意。该连接用于一片增阻、一片减阻的情形。真实应变符号相反时，两个桥路中点会向相反方向变化。]

半桥原理示意。该连接用于一片增阻、一片减阻的情形。真实应变符号相反时，两个桥路中点会向相反方向变化。这里有一个必须注意的连接规则：

两个有源应变片应占据能够使差分信号相加的桥臂。 上图使用两个上桥臂，当 SG1 增阻、SG2 减阻时，两个中点电压会反向变化。

两颗固定补桥电阻建议选用：

- 1000Ω，0.1% 或更好；
- 温度系数优先 10–25ppm/°C；
- 尽量使用相同型号和封装；
- 布置在 ADC 附近，远离明显热源。

如果 SG1 和 SG2 不满足等幅反号条件，信号灵敏度及温度补偿都会下降。

### 3.4 信号幅度估算

对一拉一压的理想半桥：

$$
V_{\mathrm{bridge}}\approx
\frac{V_{\mathrm{exc}}GF\varepsilon}{2}
$$

假设 $V_{\mathrm{exc}}=3V$，$GF=2$：

| 应变 | 半桥差分信号 |
| --- | --- |
| 20µε | 60µV |
| 50µε | 150µV |
| 100µε | 300µV |
| 200µε | 600µV |
| 500µε | 1.5mV |

这说明 ADS1220 这样的高精度 ADC 很有必要，而 nRF52832 内部的 12bit SAADC 不适合直接完成这项测量。

## 四、ADS1220 应变采集电路

ADS1220 是这套电路的模拟测量核心。

它具有 24bit Delta-Sigma ADC、可编程增益放大器、差分输入和 SPI 接口，并支持比例式电桥测量。TI 官方还提供了专门的电阻电桥测量参考方案。

### 4.1 建议的模拟前端结构

```
               3.0V 电源
                   |
             低漏电负载开关
                   |
               VEXC_BRIDGE
                   |
             +-----+------+
             |            |
            SG1          SG2
             |            |
             +-- AINP     +-- AINN
             |            |
            R3           R4
             |            |
             +-----+------+
                   |
                  GND

ADS1220:
  AIN0 / AIN1 <- 桥路差分输出（经匹配 RC 滤波）
  REFP1       <- VEXC_BRIDGE
  REFN1       <- GND
  AVDD/DVDD   <- 3.0V
  AVSS/DGND   <- GND
  SPI         <-> nRF52832
```

这是用于理解网络连接的功能图，正式原理图必须落实 ADS1220 具体引脚、PGA 输入范围、基准滤波和负载开关时序。

### 4.2 为什么使用比例式参考？

应变桥差分输出正比于激励电压：

$$
V_{\mathrm{bridge}}\propto V_{\mathrm{exc}}
$$

如果 ADS1220 的 ADC 参考也来自同一个激励电压：

$$
V_{\mathrm{ref}}=V_{\mathrm{exc}}
$$

那么转换结果中的大部分激励电压变化可以相互抵消。这种方法称为比例式测量（Ratiometric Measurement）。

它比单纯使用内部 2.048V 参考、同时让桥路使用可能变化的 3.0V 激励更适合这个项目。

### 4.3 推荐 ADC 初始配置

| 参数 | 初始值 |
| --- | --- |
| 差分输入 | AIN0 − AIN1 |
| 参考 | 外部桥路激励电压 |
| PGA | 开启 |
| 增益 | 64 倍起步 |
| 数据率 | 175 SPS 附近的标准档位 |
| 工作模式 | 连续转换，开发初期 |
| 数字滤波 | ADC 内部滤波 + 软件低通 |
| 数据就绪 | DRDY 中断 |
| 电桥激励 | 开发初期连续，后续占空比优化 |

ADS1220 的配置档位需要以选定版本数据手册为准，不是任意整数 SPS 都能设置。

对于 3.0V 外部基准、64 倍增益，理想满量程差分输入范围为：

$$
V_{\mathrm{FS}}=\pm\frac{3.0}{64}
=\pm46.875mV
$$

因此亚毫伏级信号可以测量。但必须同时检查 PGA 共模输入要求、零点失调、实际噪声和数字滤波建立时间。

### 4.4 建议预留 RC 滤波

在两条桥路差分信号线上，分别串联约 100Ω 电阻，再使用匹配电容进行滤波。可从以下设计起步：

- 每路串联电阻：100Ω。
- AINP 与 AINN 之间差模电容：10nF。
- 各输入对模拟地的共模电容：1nF，采用匹配器件。
- AVDD、DVDD：分别按官方要求就近去耦。

这些是起始值，需要结合 ADS1220 输入采样结构和实际噪声进行确认。

### 4.5 电桥开关怎么设计？

1000Ω 四电阻半桥的等效阻值为 1000Ω：

$$
I_{\mathrm{bridge}}=\frac{3}{1000}=3mA
$$

3mA 对超低功耗系统来说已经很大。

推荐在电桥正极增加低漏电高边负载开关，由 nRF52832 控制。

时序：

1. 打开电桥激励。
2. 等待电桥与模拟滤波器稳定。
3. 启动 ADC 转换。
4. 丢弃尚未稳定的数据。
5. 连续读取指定数量的样本。
6. 结束采样后关闭电桥激励。

但这里有一项重要的工程权衡：频繁开关电桥会增加模拟前端建立时间，还可能引入温度相关的零点变化。第一版建议先保持电桥连续激励，验证动态扭矩波形，再开展间歇激励实验。

TI ADS1220 还提供内置低侧开关，可用于桥路断电控制。若使用这一功能，就应按其官方电桥参考电路连接 REFN1 和桥路低端，不能同时照搬上面的高边开关接法。

### 6.3 低功耗策略

建议三个阶段：

阶段 A：开发验证。 电桥连续激励，优先确保采样准确和波形完整。

阶段 B：间歇采样。 尝试每 100ms 或 200ms 开启一个有效采样窗口，并验证扭矩峰值是否被低估。

阶段 C：动态占空比。 踏频较高、功率变化较快时提高采样占空比；稳态骑行时适当降低占空比；停止踩踏后关闭电桥，维持短时间 ANT+ 广播，然后进入休眠。

真实的 ADC 有效数据率、转换建立时间与激励稳定时间会限制可实现的占空比，因此不能预先保证 50 小时以上续航。

## 七、踏频、曲柄角度与功率计算算法

### 7.1 为什么 BMA400 不只是用来测踏频？

对于普通踏频计，只要知道每分钟多少圈即可。

但对于功率计，我们还需要尽可能准确地知道：

- 曲柄当前角度。
- 曲柄旋转方向。
- 曲柄瞬时角速度。
- 应变信号对应的是曲柄旋转周期中的哪个时刻。

因为实际踩踏扭矩在一整圈中并不恒定。

### 7.2 BMA400 曲柄相位算法

在传感器安装方向固定、重力在曲柄旋转平面内有足够投影时，可以提取两个正交方向的加速度分量：

$$
\theta(t)=\operatorname{atan2}(a_y',a_x')
$$

其中 $a_x',a_y'$ 是经过姿态坐标映射和偏置处理的信号。

然后进行相位展开：

$$
\Delta\theta_n=\operatorname{wrap}
(\theta_n-\theta_{n-1})
$$

进一步估计角速度：

$$
\omega_n\approx\frac{\Delta\theta_n}{\Delta t}
$$

需要注意，在实际骑行中，曲柄旋转会产生离心加速度和切向加速度，路面振动也会扰动重力投影。因此不能简单地认为原始 `atan2()` 结果始终等于真实曲柄角度。

我建议采取两级算法：

- 第一级：基于重力投影获得曲柄相位与完整圈事件。
- 第二级：对相位进行连续性约束和运动模型滤波，估计角速度，拒绝明显异常的相位跳变。

对于高动态踩踏，若仅使用 BMA400 无法稳定估计瞬时角速度，可以先使用每圈或较短时间窗口的平均角速度计算窗口功率，后续再考虑增加陀螺仪。

### 7.3 应变信号转换为扭矩

ADS1220 输出差分采样值，经标定得到：

$$
\tau(t)=K\left[s(t)-s_0(T)\right]
$$

其中：

- $s(t)$：当前 ADC 采样值，推荐先做电桥零点修正。
- $s_0(T)$：温度相关零点。
- $K$：扭矩标定系数，单位 N·m/ADC 计数。

如果静态加载数据表明存在明显非线性，可以增加二次项或分段标定，但第一版先采用线性模型。

### 7.4 功率计算

瞬时功率：

$$
P(t)=\tau(t)\omega(t)
$$

例如：

- 曲柄扭矩：25N·m
- 踏频：90RPM

$$
P=25\times\frac{2\pi\times90}{60}
\approx236W
$$

这里算出来的是左曲柄测得的机械功率。

如果要向码表发送估算的双侧总功率：

$$
P_{\mathrm{total,est}}=2P_{\mathrm{left}}
$$

其前提是假设左右腿贡献相等。该估算会受到左右腿力量不对称的影响。

此外，建议使用统一时间戳同步应变与角度数据，而不是先对两路数据各自平均再随意相乘。

### 7.5 一圈内扭矩波形示例

下面是理想情况下，随着曲柄角度变化的驱动扭矩。它用于说明功率采样需要跟踪一整圈，而不是只在某个角度读一次 ADC。

> [此模型假定角速度恒定、驱动扭矩为正半波，仅用于理解信号处理，并不代表真实骑行扭矩曲线。]
>
> 单圈扭矩与功率仿真 理想化示例 踏频 150 RPM 峰值扭矩 30 N·m 归一化扭矩曲线 曲柄角度 0–360° 整圈平均功率 150 W 最高瞬时功率 471 W 此模型假定角速度恒定、驱动扭矩为正半波，仅用于理解信号处理，并不代表真实骑行扭矩曲线。

### 8.2 软件运行状态

> [Chart or card]
>
> 1 SLEEP BMA400 低功耗检测运动；ADC 和电桥关闭 2 WAKE 唤醒 MCU，检查是否存在连续曲柄运动 3 MEASURE 采集应变 + 加速度，估计扭矩和角速度 4 TRANSMIT 按 ANT+ Bicycle Power Profile 发送数据 5 IDLE 停止踩踏后发送零功率，超时返回休眠

实际软件中，MEASURE 与 TRANSMIT 不是互相独占的连续状态。应变测量由 ADC 数据就绪驱动，ANT 发送由协议栈调度，两者可以在同一个主循环中并行管理。

### 8.4 核心计算伪代码

```

void process_power_sample(
    int32_t adc_raw,
    uint64_t timestamp_us)
{
    // 1. 根据标定参数换算左曲柄扭矩
    float torque = torque_from_adc(
        adc_raw,
        calibration.zero_offset,
        calibration.scale
    );

    // 2. 获取与当前应变时间戳对应的角速度
    float omega = phase_get_angular_velocity(
        timestamp_us
    );

    // 3. 计算左曲柄机械功率
    float left_power = torque * omega;

    // 4. 更新同步积分窗口
    power_integrator_add(
        timestamp_us,
        left_power
    );

    // 5. 左侧功率 x2 估算双侧总功率
    float estimated_total = 2.0f * left_power;

    power_data_update(
        torque,
        omega,
        left_power,
        estimated_total
    );
}

```

这段代码展示计算逻辑，不是完整可编译固件。真实工程需要处理负功率、角速度估计失效、ADC 过载、数据丢样及时间同步。

尤其要注意，曲柄倒转或停止时不能把仍存在的应变简单解释为正向骑行功率。

## 九、ANT+ 功率广播

对于这款设备，应当使用 ANT+ Bicycle Power Profile，而不是以前踏频计使用的 Bicycle Cadence Profile。

Nordic 提供 Bicycle Power 发射端示例，其中包含 Power-only 和 Crank Torque 等模式。

第一版建议优先实现 Page 16 标准功率数据页。

主要字段包括：

| 数据字段 | 内容 |
| --- | --- |
| Event Count | 功率更新计数 |
| Instantaneous Cadence | 当前踏频 |
| Accumulated Power | 累计功率字段，按协议定义维护 |
| Instantaneous Power | 当前功率 |
| Pedal Power | 踏板功率分布信息，无法测定时使用协议规定的无效值 |

Page 16 的功率计数和功率字段应由正式 Profile 编码器维护，不能仅发送自定义 8 字节数据包。

建议：

- 对外将设备配置为 Power-only 功率计。
- 先让码表识别并显示模拟功率。
- 再将真实测量结果接入 Profile。
- 实现码表发起的零点校准请求。
- 后续再增加制造商、产品、电池等辅助信息页。
- 不提供未经实际测量的左右功率平衡信息。

ANT+ 协议网络密钥和相关代码必须按适用的许可条款使用。

## 十、曲柄功率计的标定方案

对于双应变片方案，标定决定它能否真正成为功率计。

### 10.1 零点标定

目的：确定没有有效驱动扭矩时的桥路输出。

流程：

1. 将曲柄安装到车上。
2. 保持自行车稳定、曲柄静止。
3. 确保踏板没有受到外力。
4. 连续采集约 200–500 个 ADC 样本。
5. 检查信号是否稳定，取平均值作为零点。
6. 保存零点及测量温度。

不能在骑行过程中直接把一整圈平均应变强制修正为零，因为真实踩踏扭矩可能有非零均值。

### 10.2 已知扭矩标定

将曲柄水平放置，并在脚踏轴附近施加已知垂直载荷。

> [静态扭矩标定示意。砝码加载方向、有效力臂和装夹方式必须经过确认，避免支撑结构额外受力。]

静态扭矩标定示意。砝码加载方向、有效力臂和装夹方式必须经过确认，避免支撑结构额外受力。已知扭矩：

$$
\tau=m g L
$$

对于 170mm 曲柄：

| 加载质量 | 理论扭矩 |
| --- | --- |
| 2kg | 3.33N·m |
| 5kg | 8.34N·m |
| 10kg | 16.67N·m |
| 15kg | 25.01N·m |
| 20kg | 33.34N·m |

建议从轻载开始，确认支撑和夹具稳定后逐步加载。不要在不了解曲柄强度和夹具安全性的情况下直接悬挂大质量砝码。

每个载荷至少重复三次，记录加载与卸载数据，以检查线性、回零和滞后。

由拟合得到：

$$
\tau=K(\mathrm{ADC}-\mathrm{ADC}_0)
$$

### 10.3 多角度及串扰测试

我建议至少测试：

- 曲柄水平、垂直及中间角度下的加载响应。
- 相同驱动扭矩、不同踏板受力位置。
- 踏板侧向加载。
- 卸载回零。
- 不同环境温度下的零点变化。

尤其需要检查：当施加明显的侧向载荷但驱动扭矩接近零时，桥路输出是否错误地显示较大功率。

如果侧向串扰太大，仅靠修改软件比例系数通常不能解决，需要改变应变片位置或增加独立测量桥路。

### 10.4 动态对比测试

最终需要将自制功率计与可信的参考功率计进行骑行台对比。

推荐测试：

| 工况 | 测试内容 |
| --- | --- |
| 60RPM、100W | 低踏频稳定输出 |
| 90RPM、150W | 常规骑行 |
| 90RPM、250W | 中等偏高功率 |
| 110RPM、300W | 高踏频 |
| 变速踩踏 | 动态响应 |
| 突然停踏 | 零功率处理 |
| 短时间冲刺 | 峰值响应及 ADC 饱和 |

如果参考设备测量双侧总功率，而你的设备仅测左侧，比较时必须考虑左右腿不对称，否则不能将两者差异全部归因于传感器误差。

## 十一、PCB 与机械封装

建议第一版不要追求极致小型化。

采用双板或单板都可以，但我更推荐把电路分成：

- 传感器主板： nRF52832、BMA400、ADS1220、nPM1100。
- 应变片区域： 两片应变片直接粘贴在曲柄表面，通过短距离柔性导线连接。
- 电池区域： LiPo 电池固定在绝缘、缓冲的保护仓中。

### 11.1 PCB 设计建议

| 项目 | 建议 |
| --- | --- |
| 层数 | 四层优先 |
| 主板尺寸目标 | 约 30 × 20mm，视封装而定 |
| 地平面 | 完整连续 |
| 模拟 ADC | 远离 RF 天线和开关电源电感 |
| 应变信号线 | 成对短走线，避免高阻节点邻近时钟线 |
| 电桥滤波器 | 尽可能靠近 ADC |
| BMA400 | 固定于刚性 PCB 区域 |
| ANT 天线 | PCB 边缘，严格遵守模块净空要求 |
| SWD | 保留测试焊盘 |
| 充电 | 防水磁吸触点 |

模拟和数字部分不必盲目分割接地平面。更重要的是保持完整的电流回流路径，避免 Buck 开关电流、RF 电流经过应变测量敏感节点。

### 11.2 外壳设计

整机目标：

- 厚度尽量控制在 12–15mm 以内。
- 在曲柄内侧安装，保留足够车架间隙。
- 电池与 PCB 使用绝缘隔离。
- 应变片区域有可靠防潮保护。
- 电池不受到曲柄变形的直接挤压。
- 外壳固定不能在应变片上施加额外预载荷。

尤其不要在曲柄上钻孔、铣槽或削薄结构来容纳应变片或 PCB。 这可能破坏曲柄强度。早期测试也不建议直接使用未经验证的自改曲柄进行高强度站立冲刺或公路骑行。

## 十三、推荐的实际开发顺序

我建议不要一次性把所有硬件焊接到曲柄上，而是分五步验证。

### 01

无线功能验证

nRF52832 运行 ANT+ Bicycle Power 发射示例，发送模拟功率和踏频；用码表确认兼容性。

### 02

模拟采集验证

ADS1220 连接双应变片半桥，在实验台完成静态加载、回零、噪声和温漂测试。

### 03

曲柄相位检测

BMA400 安装在曲柄上，采集真实 XYZ 数据，建立完整转数、相位和角速度算法。

### 04

功率融合与校准

建立同步时间戳、扭矩换算和积分计算；完成功率计动态对比验证。

### 05

低功耗及整机

整合 LiPo、nPM1100、电桥开关、PCB 与外壳；验证续航、充电、防水和长期稳定性。

| 子系统 | 最终建议 |
| --- | --- |
| 主控 | nRF52832 |
| 运动检测 | BMA400，100Hz |
| 扭矩检测 | 两片 1000Ω 应变片，差动半桥 |
| 模拟前端 | ADS1220，比例式参考，PGA 64 起步 |
| 电源 | 100mAh LiPo + nPM1100 |
| 电桥功耗 | 先连续激励，后续优化 |
| 踏频算法 | 双轴相位跟踪 + 完整转数事件 |
| 功率计算 | 时间同步的扭矩 × 角速度 |
| ANT+ | Bicycle Power，Power-only 模式 |
| 精度目标 | 先验证 ±5% 的可实现性 |
| 安装 | 铝合金左曲柄、表面粘贴、无结构性改造 |

这套方案在电子技术方面没有明显的不可实现障碍，nRF52832 的计算性能、BMA400 的测量速率、ADS1220 的输入分辨能力和 nPM1100 的供电能力都能够覆盖第一版需求。

但有三项不能只通过原理图确认：

1. 应变片位置和方向。 它们决定桥路能否有效测到驱动扭矩。
2. 仅用加速度计估计瞬时角速度的误差。 高动态踩踏时尤其需要验证。
3. 电桥激励占空比与续航。 需要在实测噪声和动态功率误差之间取舍。

因此，这是一套可以进入实验板设计的完整系统方案，但还不是无需验证即可投板生产的逐引脚最终原理图。
