## 二、完整系统电源架构

> [电源路径：USB 5V 进入 nPM1100，电池连接其充电管理与电源路径，Buck 统一输出 3.0V 给所有数字、模拟和传感器电路。]

电源路径：USB 5V 进入 nPM1100，电池连接其充电管理与电源路径，Buck 统一输出 3.0V 给所有数字、模拟和传感器电路。这套架构具备三种运行方式：

| 工作状态 | 供电路径 | 行为 |
| --- | --- | --- |
| USB-C 未连接 | LiPo → nPM1100 → 3.0V | 电池供电运行 |
| USB-C 已连接 | USB-C → nPM1100 → 3.0V | 系统运行，同时管理电池充电 |
| USB-C 拔出 | 自动切换至 LiPo | 正常情况下无需重启 |

不需要额外的电源切换 MOSFET 或肖特基二极管来实现 USB/电池切换，因为 nPM1100 已集成电源路径管理。

但正式打板后的验收测试仍须验证 USB 插拔时 3.0V 的瞬态波形及 nRF52832 是否发生复位。

## 三、电源网络命名与分配

建议在立创 EDA 或 KiCad 中统一使用以下电源网络：

| 网络名 | 电压 | 用途 |
| --- | --- | --- |
| `USB_VBUS_5V` | 5.0V | USB-C 输入 |
| `VBAT` | 约 3.0–4.2V | 保护后的锂电池正极 |
| `VSYS_RAW` | 由 nPM1100 决定 | PMIC 内部电源路径关联节点 |
| `VDD_3V0` | 标称 3.0V | MCU、传感器和 ADC |
| `VDD_ANA` | 标称 3.0V | ADC 模拟电源，可选滤波 |
| `BRIDGE_EXC` | 标称 3.0V | 应变电桥激励 |
| `BRIDGE_GND` | 0V | 应变电桥回流 |
| `GND` | 0V | 系统公共地 |

最重要的限制：

- `USB_VBUS_5V` 绝对不能直接连接 `VDD_3V0`。
- `VBAT` 不能直接连接 nRF52832 或 BMA400。
- `VSYS_RAW` 不是稳压的 3.0V，不能直接当作 MCU 电源。
- `BRIDGE_GND` 与系统地最终必须有明确连接。
- nRF52832 需要遵循其裸芯片对应的 DEC 去耦和供电参考电路。

nPM1100 的未稳压系统电源可能在 3–5.5V 范围变化，因此应使用它的 3.0V Buck 输出，而非直接使用 VSYS 给 nRF52832 供电。

## 四、USB-C 充电与供电输入电路

本版 USB-C 只使用标准 5V，不进行 USB PD 协商，也不需要快充控制器。

### 4.1 USB-C 接口接线

建议采用 16Pin USB-C 母座，按以下网络连接：

| USB-C 引脚 | 连接 | 说明 |
| --- | --- | --- |
| A4、A9、B4、B9 | `USB_VBUS_5V` | 5V 输入 |
| A1、A12、B1、B12 | GND | 电源地 |
| A5 / CC1 | 5.1kΩ → GND | 用电端识别 |
| B5 / CC2 | 5.1kΩ → GND | 用电端识别 |
| A6/B6、A7/B7 | 数据线预留 | 可用于 PMIC 端口检测 |
| SBU1/SBU2 | NC | 不使用 |

CC1、CC2 必须各自连接独立的 5.1kΩ 电阻，不能互相短接。

nRF52832 本身没有 USB 控制器。 USB-C 在这个方案中只负责供电，并不能直接通过 USB 给 nRF52832 下载程序；程序烧录仍然使用 SWD/J-Link。

nPM1100 具有 USB D+/D− 端口检测能力。如果想利用其自动识别 USB 充电端口的功能，可以将 USB-C 两组并联后的 D+、D− 分别接到 nPM1100 对应输入。否则可以仅使用 USB-C 的 5V 电源输入，并将 PMIC 的输入限流设置为保守的 100mA 档位。

### 4.2 USB-C 电源保护

推荐输入网络：

```
USB-C VBUS
     |
     +----- ESD/TVS 对 GND
     |
     +----- 2.2µF / 25V
     |
     +----- USB_VBUS_5V
                  |
             nPM1100 VBUS
```

建议：

| 位号 | 器件 | 初始规格 |
| --- | --- | --- |
| J1 | Type-C 16Pin 母座 | USB 2.0 |
| R1 | CC1 下拉 | 5.1kΩ，1% |
| R2 | CC2 下拉 | 5.1kΩ，1% |
| D1 | VBUS TVS | 适合 USB 5V 输入的低漏电保护器件 |
| C1 | VBUS 输入电容 | 2.2µF，25V X5R |
| TP1 | 测试点 | USB_VBUS_5V |

TVS 的工作反向电压、钳位电压及漏电流需要与 PMIC 输入保护能力匹配。USB VBUS 输入电容的有效容量也应考虑直流偏压降额。

## 五、nPM1100 充电、供电和 Buck 最小电路

这是本次硬件改版新增的核心模块。

### 5.1 选用型号

U4：nPM1100-QDAA-R，QFN24，4 × 4mm。

选择标准充电终止电压版本，配合 4.2V 满充的 1S LiPo 电池。Nordic 官方资料确认 QD 为 QFN24 封装，AA 为标准终止电压系列。

### 5.2 nPM1100 主要引脚与网络

以下使用官方信号名称定义连接，具体 QFN24 物理引脚号应从 QFN24 的 Pin Assignment 表导入，不得套用 WLCSP 的球位编号。

| nPM1100 信号 | 连接 | 初始设置 |
| --- | --- | --- |
| VBUS | USB_VBUS_5V | USB 5V 输入 |
| VBAT | BAT_PROTECTED+ | 电池保护后的正极 |
| AVSS / PVSS | GND | 系统地 |
| VSYS | VSYS_RAW | 按参考设计去耦，不直接供电给 MCU |
| SW | Buck 电感一端 | 高频开关节点 |
| VOUTB | VDD_3V0 | 3.0V 输出 |
| DEC | 按参考设计去耦 | PMIC 内部去耦节点 |
| VTERMSET | 配置网络 | 4.2V 终止电压 |
| ICHG | 27kΩ → GND | 约 20mA 充电 |
| ISET | 低输入限流设置 | 首版保守选择 100mA |
| VOUTBSET0 | 高电平选择网络 | 3.0V 配置 |
| VOUTBSET1 | 高电平选择网络 | 3.0V 配置 |
| MODE | 低电平 | Buck 自动模式 |
| NTC | 电池 NTC 网络 | 充电温度保护 |
| CHG | 可选充电状态电路 | 充电状态 |
| ERR | 可选错误状态电路 | 错误指示 |
| SHPACT/SHPHLD | 按官方常规运行电路 | 预留 Ship Mode 控制 |

根据 Nordic 官方开发板资料，27kΩ 的充电设置电阻对应约 20mA 充电电流。VOUTBSET0 和 VOUTBSET1 同时选择高电平时，Buck 输出为 3.0V；高电平选择应按官方规定连接到 VSYS 等指定网络，而不是随意连接任意 GPIO。

### 5.3 PMIC 外围元件

建议从 Nordic nPM1100 官方的正常工作参考配置开始。

| 器件 | 初始规格 | 用途 |
| --- | --- | --- |
| L1 | 2.2µH，按参考设计选饱和电流 | Buck 电感 |
| C2 | 10µF，6.3V | Buck 输出 |
| C3 | 10µF，6.3V | VSYS 去耦 |
| C4 | 10µF，6.3V | VBAT 去耦 |
| C5 | 1µF，10V | DEC 去耦 |
| R3 | 27kΩ，1% | 20mA 充电电流 |
| NTC | 10kΩ，按电池 B 值选型 | 电池温度检测 |

这些电容、电感是原理图设计的起始选值，位置和数量必须以 QFN24 官方参考电路为准，尤其不要将内部 DEC、SW 和 VSYS 当成普通电源脚随意连接。

### 5.4 关于一边充电一边运行

nPM1100 的动态 Power Path 允许 USB 插入后继续为系统提供电源，并管理电池充电。但需要考虑系统负载对输入功率预算和充电电流的影响。

例如，完整应变桥连续工作时约消耗 3mA，远低于 100mA 的 USB 输入限流预算；nRF52832 的 RF 发射峰值也处于该 PMIC 的供电能力范围内。仍应实测 USB 插拔和充电状态下的纹波，避免 Buck 开关噪声影响微伏级的桥路测量。

## 六、锂电池与电量检测

### 6.1 电池接口

建议使用 3Pin 电池连接器：

| 引脚 | 网络 | 功能 |
| --- | --- | --- |
| 1 | BAT_PROTECTED+ | 保护后电池正极 |
| 2 | BAT_NTC | 电池热敏电阻 |
| 3 | GND | 电池负极 |

选择自带过充、过放、短路保护电路的 100mAh LiPo 电池包。充电器正常充电控制和电池保护板的故障保护是两种不同功能，不能相互代替。

如果选用的是独立 NTC 引线电池包，需要确认 NTC 的阻值、B 参数及接线方式与 nPM1100 的温度检测网络匹配。

### 6.2 电池电压检测

由于 MCU 工作在稳压的 3.0V，读取 VDD 无法直接知道 LiPo 当前电压。

建议增加：

```
BAT_PROTECTED+
       |
    受控开关
       |
      1MΩ
       |
       +---------- P0.02 / SAADC
       |
      1MΩ
       |
      GND
```

当电池为 4.2V，ADC 输入约为 2.1V，不超过 nRF52832 的 3.0V GPIO 电源电压。

第一版可以通过预留负载开关封装和电阻焊盘实现，开发时也可以先保持分压上电，但需注意常通分压网络会持续耗电。

必须检查关断状态是否存在从 VBAT 经分压、ADC 输入钳位结构向 MCU 反向供电的路径。 不建议只用一个 MCU GPIO 直接作为 4.2V 高边开关。

### 6.3 额外预留的电源调试功能

我建议增加：

- VBUS、VBAT、VSYS、VDD_3V0、GND 测试点。
- 系统 3.0V 串联 0Ω 电阻或可拆跳线，用于电流测量。
- USB 供电与电池供电切换测试点。
- LED 状态指示焊盘，但调试阶段之外可不贴装 LED。
- 一个按键用于唤醒或软件调试（可选）。

不要在每个电源轨上串联高阻电流采样电阻，否则可能影响 RF 发射瞬态和模拟精密测量。

## 七、nRF52832-QFAA 裸芯片最小电路

在 V1.1 中，nRF52832 的最小系统基本不变，但统一由 nPM1100 的 3.0V 输出供电。

### 7.1 供电与内部稳压

选择 nRF52832 内部 LDO 工作模式，首版不安装片内 DC/DC 对应电感网络。

主电源：

```
nPM1100 VOUTB
      |
   VDD_3V0
      |
      +--- nRF52832 VDD
      +--- nRF52832 其他 VDD
      |
      +--- 4.7µF
      +--- 100nF
      |
     GND
```

同时必须按 Nordic QFAA 官方 Internal LDO 参考电路处理 DEC1、DEC2、DEC3、DEC4、DCC 等电源相关管脚，而不是把 DEC 管脚直接连到 VDD。

官方参考 BOM 包括：

| 元件 | 参考参数 |
| --- | --- |
| 高频晶振 X1 | 32MHz，CL=8pF |
| 低频晶振 X2 | 32.768kHz，CL=9pF |
| 晶振负载电容 | 12pF C0G，共四颗 |
| MCU 去耦 | 100nF、1µF、4.7µF，按官方位置 |
| RF 匹配 | 3.9nH、0.8pF、100pF 等，按官方拓扑 |

这些值来自 Nordic QFAA LDO 官方参考电路。

### 7.2 时钟

- XC1/XC2 接 32MHz 晶振。
- P0.00/XL1、P0.01/XL2 接 32.768kHz 晶振。
- 两组晶振靠近 MCU，走线短、对称，并避免跨越地平面分割。
- 不建议在高频晶振附近布置 Buck 的 SW 节点或电感。

### 7.3 射频

nRF52832 ANT 引脚连接 Nordic 对应封装官方 RF 匹配网络，再接板载 2.4GHz 天线或外接 RF 接口。

对于首次裸芯片 RF 打板，强烈建议从 Nordic 官方参考布局复制 RF 元件位置、接地过孔和走线几何形状。 单纯按原理图连接 3.9nH 和 0.8pF，不足以保证天线性能。

建议首板增加 U.FL 射频接口或可切换的 50Ω 测试接口，以便先用外部天线验证 ANT+，再优化板载天线。

## 八、BMA400 最小电路

采用 I²C 接口。

| BMA400 引脚号 | 信号 | 连接 |
| --- | --- | --- |
| 1 | SDO | GND（地址选择） |
| 2 | SDX/SDA | nRF P0.26 |
| 3 | VDDIO | VDD_3V0 |
| 4 | NC | 不连接 |
| 5 | INT1 | nRF P0.11 |
| 6 | INT2 | nRF P0.12 |
| 7 | VDD | VDD_3V0 |
| 8 | GNDIO | GND |
| 9 | GND | GND |
| 10 | CSB | VDD_3V0 |
| 11 | NC | 不连接 |
| 12 | SCX/SCL | nRF P0.27 |

外围：

- SDA 上拉 4.7kΩ 至 3.0V。
- SCL 上拉 4.7kΩ 至 3.0V。
- VDD 就近 100nF。
- VDDIO 就近 100nF。
- INT1/INT2 可预留 10kΩ 上拉位置，实际根据中断输出配置决定是否安装。

引脚和 100nF 去耦建议来自 Bosch 官方 BMA400 数据手册。

BMA400 不建议断电，因为它需要保持低功耗运动唤醒功能。

## 九、ADS1220 + 双应变片半桥电路

### 9.1 ADS1220 供电

ADS1220 的 AVDD、DVDD 采用 3.0V 供电，分别配置就近去耦。

建议将 `VDD_ANA` 通过 0Ω 电阻从 `VDD_3V0` 引出，预留后续更换磁珠或低噪声电源滤波的能力。

第一版保持连续供电，暂时不通过负载开关关闭 ADC。

### 9.2 ADS1220 TSSOP-16 引脚表

| 引脚 | 名称 | 连接 |
| --- | --- | --- |
| 1 | SCLK | P0.13 |
| 2 | CS | P0.16 |
| 3 | CLK | GND，内部时钟 |
| 4 | DGND | GND |
| 5 | AVSS | GND |
| 6 | AIN3/REFN1 | 未使用，按手册处理 |
| 7 | AIN2 | 未使用，按手册处理 |
| 8 | REFN0 | BRIDGE_GND |
| 9 | REFP0 | BRIDGE_EXC |
| 10 | AIN1 | 桥路负信号 |
| 11 | AIN0/REFP1 | 桥路正信号 |
| 12 | AVDD | VDD_ANA |
| 13 | DVDD | VDD_3V0 |
| 14 | DRDY | P0.17 |
| 15 | DOUT/DRDY | P0.15 |
| 16 | DIN | P0.14 |

该表对应 TI 最新 ADS1220 TSSOP-16 数据手册。

### 9.3 双应变片桥路

采用两个有源应变片 SG1/SG2，加两颗 1000Ω 精密电阻组成半桥。

假设两片应变片受力方向相反：

```
                  BRIDGE_EXC (3.0V)
                      |
              +-------+-------+
              |               |
             SG1             SG2
              |               |
              +-- SIG+        +-- SIG-
              |               |
            R_COMP1         R_COMP2
              |               |
              +-------+-------+
                      |
                  BRIDGE_GND
```

推荐器件：

| 器件 | 参数 |
| --- | --- |
| SG1/SG2 | 1000Ω、GF≈2、同型号 |
| R_COMP1/R_COMP2 | 1000Ω、0.1%、≤25ppm/°C |
| R_IN+ / R_IN− | 100Ω |
| C_DIFF | 10nF |
| C_CM+ / C_CM− | 1nF，匹配 |

桥路正激励连接 ADS1220 REFP0，桥路负激励连接 REFN0，采用比例式参考，减小电源变化引入的增益误差。

### 9.4 电桥供电方式

第一版建议为电桥设计一个可配置的激励网络：

```
VDD_3V0
    |
  JP_BRIDGE
    |
    +---- 0Ω 直供路径（默认装）
    |
    +---- 低漏电负载开关路径（预留）
    |
BRIDGE_EXC
```

这样在 V1.1 测试阶段，电桥可以持续使用 3.0V 激励，便于获得稳定的动态应变波形。后续再用负载开关降低功耗。

注意两条路径应通过不同装配选项互斥，不能因为预留而把开关旁路永久短接。

电桥连续激励的电流约为：

$$
I=\frac{3.0V}{1000\Omega}=3mA
$$

电桥本身的功耗约 9mW。对 100mAh 小锂电池而言，这一部分可能成为续航主要限制，因此建议把低功耗电桥激励作为第二版的重点优化任务。

### 9.5 充电状态对模拟测量的影响

USB 接入后，充电器和 Buck 都可能使电源噪声增加。建议测量以下三种情况下的 ADS1220 零点噪声：

- 仅电池供电。
- USB 连接并充电。
- USB 连接、电池接近满电。

如果 ADC 噪声在 USB 充电时明显增大，优先检查 PMIC 电感与 ADC 的距离、接地回流和桥路引线屏蔽，而不是直接提高软件滤波强度。

## 十四、打样与上电检查

我建议将验证分为四轮，避免上来就同时调试整套功率计。

| 阶段 | 测试内容 | 合格判断 |
| --- | --- | --- |
| 电源验证 | USB-C 5V、LiPo、充电、3.0V Buck | 无异常发热、输出正常、插拔稳定 |
| MCU 验证 | SWD、32MHz、32.768kHz、射频 | J-Link 识别，程序与 ANT 正常 |
| 传感器验证 | BMA400 I²C、ADS1220 SPI | 原始数据、寄存器和中断正常 |
| 功率计验证 | 半桥加载、相位跟踪、ANT+ | 扭矩可标定、踏频与功率可广播 |

上电顺序尤其重要：

1. 先不连接电池，仅接 USB-C，测量 USB_VBUS_5V、VSYS_RAW 和 VDD_3V0，确认 PMIC 正常。
2. 断电后接入受保护的 1S LiPo 电池，验证电池独立供电。
3. USB 插拔时用示波器观察 3.0V 电源，不应出现造成 MCU 复位的电压跌落。
4. 再连接 J-Link，测试 MCU 及晶振。
5. 最后采集应变桥数据，并比较充电与非充电时的模拟噪声。

### 三个投板前必须确认的关键点

第一，nPM1100-QDAA 的 QFN24 引脚映射、外围电容、电感和 NTC 网络必须依据其 QFN24 官方参考设计逐项完成，不能把 WLCSP 的球位编号拿来使用。

第二，nRF52832 的 DEC 引脚、32MHz 晶振和 ANT 匹配网络必须按 QFAA 内部 LDO 的官方参考设计布局。这关系到芯片启动可靠性和 ANT+ 射频性能。

第三，双应变片电桥和 ADS1220 必须实现真正的差分输入与比例式参考，并在 USB 充电时检查模拟噪声。对于微伏级测量，供电纹波与布局可能比 ADC 的标称分辨率更关键。

官方设计依据：Nordic nPM1100 规格书及硬件设计资料 · nRF52832 官方参考电路 · BMA400 数据手册 · ADS1220 数据手册。

这版 V1.1 已经明确了各功能模块、电源路径、接口网络、关键器件和 PCB 分区，可作为完整原理图设计输入。 但它仍属于详细硬件设计说明，而不是已逐引脚完成 ERC/DRC、可以直接送厂的最终工程文件。正式打样前，nPM1100 QFN24 的物理引脚、电源参考器件、RF 布局与电池保护必须在 EDA 工程中完成最终核验。
